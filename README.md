## Project 2 - Full House (Multiplayer turn-based card battle / strategy game)

# What and why:

    - What: A web-app game where players recieve random cards (that heal, attack, defend, curse, etc.) and they take turns using these cards against eachother

    - Why: Roguelike deck-building games have blown up recently (Slay the spire, bolatro, dominion, etc.) but all of these games are not playable online and are singleplayer. I think there is a gap for a similiar game that is web-based. 

# For whom:

    - Anyone who enjoys strategy or card games, especially students and friends who want something they can open in a browser and play together quickly.

# Scope:

    - I don't think this is too easy of a project since there is a lot of logic involved (multiplayer, turn order, random card generation, different card effects, win/loss conditions, real time sync between players, etc.)

    - I don't think this is too difficult of a project since mechanics can be kept relatively simple and be updated later.
